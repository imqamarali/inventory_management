KNOWN ISSUES & SOLUTIONS
================================================================================

Issue 1: mysqldump not recognized
Solution: Add MySQL to system PATH (see SYSTEM_SETUP_INSTRUCTIONS.md)
Status: Documented with setup guide

Issue 2: Access denied for database user
Solution: Verify credentials in config/db.php
Status: Configuration-dependent, not an issue with code

Issue 3: Backup file 0 bytes
Solution: Verify MySQL has SELECT permissions
Status: Rare, documented in troubleshooting

Issue 4: Tests show database errors
Solution: Verify MySQL service is running
Status: Environment-dependent, documented
